🌤️ Clima App
Aplicativo mobile de previsão do tempo desenvolvido em Flutter, que consome a 
API REST pública Open-Meteo para buscar cidades e exibir o clima atual e a previsão dos próximos dias.

✨ Funcionalidades:
Busca de cidades pelo nome, lista de resultados com cidade, estado e país
Clima atual: temperatura, sensação térmica, umidade e velocidade do vento
Previsão diária com temperaturas mínima e máxima
Ícones e descrições conforme as condições do tempo
Indicador de carregamento e mensagens de erro.

🌐 API utilizada:
Nome: Open-Meteo
Documentação:	https://open-meteo.com/en/docs
Busca de cidades:	https://geocoding-api.open-meteo.com/v1/search?name={cidade}
Previsão do tempo:	https://api.open-meteo.com/v1/forecast?latitude={lat}&longitude={lon}
Autenticação:	Não é necessária.
